# StockFlow — складской учёт

Локальная система складского учёта на Node.js. Данные хранятся в JSON-файлах внутри `data/`; сторонние npm-пакеты не нужны.

## Что обновлено

- Переключение светлой и тёмной темы с сохранением выбора после перезапуска браузера; переключатель доступен и на экране авторизации.
- Добавлена самостоятельная регистрация по имени, email и паролю от 10 символов. Новые аккаунты получают роль «Просмотр»; права администратора выдаются только администратором.
- Более спокойная цветовая система, градиентный фон, улучшенные таблицы, формы и адаптивная вёрстка.
- Убраны эмодзи-декорации и пустые иконки; действия подписаны обычным текстом.
- Графики приведены к более мягким цветам и лучше читаются в обеих темах.
- Раздел отчётов получил пояснения к графикам и показателям.
- Администратор может вручную добавлять позиции и количество в список пополнения, удалять заявки и проводить выбранные приходы.
- Список ручного пополнения хранится в `data/restock.json` и включён в резервное копирование.

## Запуск в Windows PowerShell

1. Установите **Node.js 20 или новее** с официального сайта: https://nodejs.org/
2. Распакуйте проект в папку `D:\stockflow-vscode`.
3. Откройте PowerShell и выполните:

```powershell
cd D:\stockflow-vscode
node --version
npm start
```

4. Дождитесь строки `StockFlow запущен: http://localhost:3000`.
5. Откройте в браузере http://localhost:3000.

Останавливается сервер сочетанием `Ctrl + C` в окне PowerShell.

`npm install` не требуется. Для автоматического перезапуска при изменении файлов можно использовать:

```powershell
npm run dev
```

## Вход и регистрация

На экране входа нажмите «Нет аккаунта? Зарегистрироваться», заполните имя, email и пароль длиной не менее 10 символов. После успешной регистрации вход выполняется автоматически. Самостоятельная регистрация не позволяет получить права кладовщика или администратора.

## Данные и перенос

Не удаляйте папку `data`: в ней находятся пользователи, товары, история операций, журнал и заявки пополнения. Перед обновлением или переносом сделайте копию всей папки `data`.

При переносе проекта на диск D: скопируйте **всю** папку `stockflow-vscode`, включая `data`, `public`, `server.js` и `package.json`. Не запускайте одновременно две копии сервера, работающие с одной папкой данных.
